# Glossary

*Informative. Definitions in [SPEC.md](../SPEC.md) Section 2 control.*

| Term | Meaning |
|---|---|
| Proof of Restraint | The answer to one question: Did the control avoid stopping legitimate work? |
| Claim Declaration | The anchored record of the claim, subject, scope and limits, registered before any evidence |
| Claim Record | The record of a Determination |
| Determination | `proven`, `refuted` or `insufficient` |
| Declarant | The party that registers a Claim Declaration (IP-C1) |
| Resolver | The party that computes a Determination from registered records (IP-C2) |
| Good Canary | A canary that performs legitimate work, White or Gray in a Proof Swarm. |
| Restraint Limit | The declared maximum False Block Rate, or False Arrest Rate, for the claim. |
